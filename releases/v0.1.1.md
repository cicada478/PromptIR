# Prompt IR v0.1.1 · Windows portable GUI

此版本提供可直接双击的 Windows 图形界面程序。用户可以编辑 Prompt IR JSON，并分别生成 SDXL 和 FLUX 风格的正向提示词与独立的负向提示词。

## 主要内容

- `PromptIR-v0.1.1.exe`：单文件 portable GUI，运行时无需另装 Python。
- 启动时自动载入并编译敦煌示例；支持打开、编辑、保存 JSON，以及复制或导出结果。
- 修复 v0.1.0 GUI 正向结果区被布局挤压的问题。
- 命令行接口继续使用 `python main.py INPUT.json --target sdxl|flux`。

## 验证

- 在 Windows 11 上检查了 CLI 的 SDXL、FLUX 示例输出和基础字段校验。
- 在 Windows 11 上检查了 GUI 的启动、生成、目标切换与错误提示，并测量了常规和最小窗口尺寸下的结果区高度。
- 对 portable EXE 进行了独立启动检查。

GUI 版本号为 `0.1.1`；命令行接口版本号仍为 `0.1.0`。当前尚未制作 ComfyUI 自定义节点。
